# 📊 Excel Retail Sales Dashboard

## 📌 Overview
This repository contains an **Excel dashboard** designed to analyze and summarize retail sales performance. The dashboard converts raw sales and expense data into **clear, visual insights** that support quick and effective decision-making.

It provides a high-level overview of retail performance across multiple brands, allowing users to assess trends and comparisons without manually reviewing detailed spreadsheets.

---

## 🔑 Key Metrics
The dashboard focuses on the following core performance indicators:

- **Total Units Sold**  
  Displays the total number of products sold across all brands, providing a quick snapshot of overall sales performance.

- **Units Sold by Brand**  
  Breaks down sales volume by individual brands (e.g., *DreamCo* and *Sodapop*), enabling easy comparison of brand contributions.

- **Average Expenses**  
  Shows the average expenses related to sales activity, helping evaluate cost efficiency alongside sales performance.

---

## 📈 Dashboard Visuals
To improve clarity and usability, the dashboard includes:

- **Bar / Column Charts** – Visual comparison of units sold by brand  
- **KPI Summary Cards** – Highlight key figures such as total units sold and average expenses  
- **Aggregated Totals** – Provide context for individual brand performance within overall business results

---

## 💡 Insights Enabled
Using this dashboard, users can:

- Identify the best-performing brand by sales volume  
- Understand how each brand contributes to total sales  
- Monitor expense levels relative to sales performance  
- Use summary insights as a foundation for deeper analysis

---

## ✅ Purpose
This Excel dashboard serves as a **decision-support tool** for analysts, students, and business stakeholders. By transforming detailed Excel data into an accessible and visually driven summary, it enables faster insights and more confident decision-making.
