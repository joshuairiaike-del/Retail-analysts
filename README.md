# Retail Analysis

  ---Excel Dashboard Explanation
This repository contains an Excel dashboard designed to analyze and summarize retail sales performance. The dashboard transforms raw sales and expense data into clear, visual insights that support quick decision-making.
📊 Dashboard Overview
The Excel dashboard provides a high-level view of retail performance across brands. It allows users to quickly assess overall sales volume, compare brand performance, and review expense trends without manually reviewing detailed data tables.
🔑 Key Metrics
The dashboard focuses on the following core performance indicators:
Total Units Sold
Displays the total number of products sold across all brands, giving an immediate snapshot of overall sales performance.
Units Sold by Brand
Breaks down total sales volume by individual brands (e.g., DreamCo and Sodapop), enabling direct comparison of brand contributions.
Average Expenses
Shows the average expenses associated with sales activity, helping evaluate cost efficiency alongside revenue performance.
📈 Visual Elements
To improve clarity and usability, the dashboard includes:
Bar / Column Charts – Used to compare units sold between brands visually.
KPI Summary Cards – Highlight important figures such as total units sold and average expenses at a glance.
Aggregated Totals – Provide context for individual brand performance within overall business results.
💡 Insights Enabled
Using this dashboard, users can:
Identify the best-performing brand by sales volume
Understand how each brand contributes to total sales
Monitor expense levels relative to sales performance
Use summary insights as a starting point for deeper analysis
✅ Purpose
This dashboard serves as a decision-support tool for analysts, students, and business stakeholders by converting detailed Excel data into an accessible and visually driven summary.
