# Retail Analysis
📊 Excel Retail Sales Dashboard
Overview
This repository contains an Excel dashboard designed to analyze and summarize retail sales performance. It transforms raw sales and expense data into clear, visual insights that support fast and informed decision-making.
The dashboard provides a high-level view of retail performance across multiple brands, allowing users to assess trends and comparisons without manually reviewing detailed spreadsheets.
🔑 Key Metrics
The dashboard highlights the following core performance indicators:
Total Units Sold
Displays the overall number of products sold across all brands, offering a quick snapshot of total sales performance.
Units Sold by Brand
Breaks down total sales volume by individual brands (e.g., DreamCo and Sodapop), enabling direct comparison of brand contributions.
Average Expenses
Shows average expenses associated with sales activity, helping evaluate cost efficiency alongside sales performance.
📈 Visual Components
To enhance usability and clarity, the dashboard includes:
Bar / Column Charts – Visual comparison of units sold by brand
KPI Summary Cards – At-a-glance metrics such as total units sold and average expenses
Aggregated Totals – Contextualize individual brand performance within overall business results
💡 Insights Enabled
With this dashboard, users can:
Identify the best-performing brand by sales volume
Understand each brand’s contribution to total sales
Monitor expense trends relative to sales performance
Use summary metrics as a starting point for deeper analysis
✅ Purpose
This Excel dashboard serves as a decision-support tool for analysts, students, and business stakeholders. By converting detailed transactional data into a visually driven summary, it enables faster insights and more confident decision-making.
